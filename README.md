# planarian-serotonergic-rnai
Code for Emili et al 2024

## About

This repository contains the code for the analyses in the manuscript 'Multiplex single-cell analysis of serotonergic neuron function in planarians reveals widespread effects in diverse cell types'.

Note: in the interest of a potential user of this code, we note that relative paths for the location of other code, folders, and data, have remain unchanged. Several items such as h5ad objects, some plots, and other third-party data sets (such as genomes or transcriptomes), have been excluded from this repository for practicality or due to file size limit.
